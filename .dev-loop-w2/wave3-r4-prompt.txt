## 적용된 수정
1. **[high 하트비트 실패 은폐]**: `createHeartbeatWriter` 의 bare `catch{}` → `established` 플래그 상태기계.
   **첫 발행**(spawn 시 register) 실패 = **throw**(`heartbeat_unwritable`) → `superviseSession` 이 이미 뜬 그룹 SIGKILL +
   registry release + settle(알람 무장 전이라 백스톱 없는 세션이 조용히 안 돎). **이후 발행** 실패 = stderr 감사 1줄 + 계속
   (첫 발행 성공했으면 유효 pgid 파일이 이미 디스크에 있어 백스톱 존재 · 일시 EIO 로 건강한 세션 죽이는 건 과함). runner 는
   heartbeat_unwritable 을 전이확인 전 실패로.
2. **[medium#1 출력캡 groupAlive 조기반환 유실]**: `capKillObserved` 클로저 플래그를 `onSelfExit` 의 groupAlive
   조기반환 **전에** 세팅 → kill_at reap 분기가 killed 아닌 `output_cap` 으로 settle. runner 는 실패로 차단.
3. **[medium#2 never-throw 누수]**: `sdkGenTimeout()`/`sdkMaxTurns()` 를 try/catch 안으로(`config_error`). `main()` 을
   `emitAndExit(RunJobResult)` 공유로 리팩터 + 전체 래핑 → 스펙 읽기/JSON.parse/배선 throw 도 구조화 config_error 를
   stdout 에 내고 exit 1(type-only RunJobResult import — 런타임 소거, 순환 없음).
