## 적용된 수정
1. **[critical: nonce 미탑재로 verify→signal PID재사용 창]**: `ReapDecision` 의 kill·scan-then-kill 이 **nonce 를 실어**
   데몬이 신호 직전 재검증하게. 헤더 계약에 '신호 직전 nonce 재검증(decision≠signal)' 명시. scan=발견일 뿐 nonce-free
   kill 불허. **과대주장 정정**: "PID재사용 닫음"→"register-lag 닫힘 · PID재사용은 좁힘(Darwin ms급 TOCTOU 원리적
   잔여 · cgroup 만 완전폐쇄)".
2. **[high: S1 enum/교차규칙 미검증]**: contract-client 가 step/action 을 **enum 멤버십**으로 검증(STEP_VALUES·
   ACTION_VALUES 미러, contract.ts SSoT 주석) + 교차규칙(action=generate ⟹ stage 비어있지 않은 string). stage=string|null
   은 비-generate 에 유지.
3. **[high: S1 이 worker.ts ingest 가드를 fail-open 으로 뒤집은 회귀]**: fail-closed 로 — action==="ingest" 를 **적극
   확인**할 때만 진행. read 실패(throw→null)·다른 action → 차단. 주석에 'core 에 ingest 현재-phase 게이트 없음 +
   파괴적이라 fail-closed' 근거.
4. **[high: alive+startedAtMs=null 을 PID재사용으로 오분류]**: owner-state 3분기 — alive+match→wait · alive+다른숫자→
   reap진행 · **alive+null(unknown)→wait**(살아있는 supervisor 세션 kill 방지) · !alive→reap.
5. **[medium: parse 가 pgid 불변식 미강제]**: live/leaked 의 pgid=int>1 을 parse 도 강제(asPgid).
