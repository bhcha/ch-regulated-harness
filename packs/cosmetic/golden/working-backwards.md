# 워킹백워드 — [예시] 이지듀 멜라 비 토닝 앰플 쿠션 (화장품 PoC 샘플)

> ⚠️ **이 파일은 교체 가능한 예시(화장품 샘플)입니다.** 실제 사용 시 **자신의 제품 워킹백워드(.docx → md)로 이 파일을 교체**하세요.
> 도메인이 화장품이 아니면(의약외품/건기식/의약품) 해당 제품의 근거로 바꿔야 합니다.
> 제품 근거 원천(.docx → md). ingest 가 여기서 `claim-basis.json` 을 결정적으로 추출한다.
> 근거가 명시되지 않은 효능은 자동으로 `unknown`/빈 배열(=주장 불가)로 남는다(fail-closed).

## 제품 개요
- 제품유형: 색조화장품(쿠션 파운데이션), 본품 15g + 리필 15g
- 색상: 19호 페어 / 21호 / 22호 라이트 베이지 / 23호 베이지
- 핵심 사용 가치: 일상 커버력, 촉촉한 사용감, 피부 밀착, 화사한 톤 표현

## 기능성·인증 근거 (있는 것만 기재)
- 자외선차단: SPF 50+ PA+++ **자외선차단 기능성화장품으로 식약처에 보고**된 제품이다.
- 미백/주름: 별도 기능성 심사·보고 근거 없음 → 표시 불가.
- 더마테스트 등 인증: 보유 시에만 기재(현재 별도 자료 없음).

## 보유 실증 자료
- 현재 인체적용시험/인체외시험 등 별도 실증 파일 없음 → 실증 그래프·before/after 블록 비활성.

## 소비자 가치 (VOC 정합)
- 리뷰에서 자주 언급: 커버, 기미(잡티 가림), 촉촉, 밀착, 화사 — 이는 **사용 경험 언어**이며 효능 단정이 아니다.
- '미백'은 리뷰에서 거의 언급되지 않음(법정 기능성 미보유) → 감성 헤드라인 금지, 법정 슬롯 불가.

## 금지/주의 (내부)
- 속효 단정('단 1일 만에'), 절대표현('국내 최초', '1위', '무결점') 금지.
- 미승인 기능성(미백/주름) 효능 표현 금지. '톤업/화사/가려준다'는 일반 표현으로만 사용.
